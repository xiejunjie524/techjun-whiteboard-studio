# AI Agent vs Chatbot Demo

This directory contains a complete 1080p reference deliverable produced with Tech Jun Whiteboard Studio.

## Files

- `techjun-agent-demo-1080p.mp4`: final 1920x1080, 60 fps, H.264/AAC video.
- `narration.srt`: eight-scene Chinese narration source.
- `render-config.json`: unattended 1080p rendering configuration.
- `captions-and-cards.ass`: final caption and information-card timeline.

## Output

- Duration: 44.7 seconds
- Scenes: 8
- Voice: local Voicebox Chinese narration
- Graphics: whiteboard drawing, information cards, burned-in captions
- Audio: narration, low-volume BGM, and transition/card sound effects
