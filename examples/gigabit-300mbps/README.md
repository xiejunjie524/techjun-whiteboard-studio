# 千兆宽带测速只有 300Mbps

本示例是一条约 50 秒的 8 幕白板科普视频，主题是排查家庭千兆宽带测速偏低的常见原因。

- 输出：`rendered/final-dayi-1920x1080.mp4`
- 画面：1920×1080、60fps、8 幕、自动语义转场
- 音色：本地 Voicebox `Dayi Clone`
- 字幕：`captions.ass`，根据旁白段落和画面时间线编排
- 手部：`handVisibility: "ink-only"`，只在线稿落墨时显示

智画接口恢复 token 后，可替换 `rendered/scene-01` 到 `scene-08` 的 PNG 并重新运行渲染，不需要修改字幕、旁白和时间线。
